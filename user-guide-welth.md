## 1. What is Welth?
**Welth** is a user-friendly platform that helps users manage health conditions using information from the World Health Organization (WHO). The platform allows users to track symptoms, order prescribed medications, monitor medication intake, book nearby medical appointments, and manage ongoing health conditions. It is designed for patients, caregivers, doctors, and all users above the age of 16.

## 2. Create an Account 
1. Go to Google Play Store (Android) or App Store (iOS).
2. Install the Welth app.
3. Create an account using username and password.
_Alternatively, tap 'Continue with Google' to create your account via Google._
4. Set your default condition(s) on the next pop-up page.
+ _**Note:** Ensure that the condition is diagnosed by a professional. If not, tap 'Only Explore' at the bottom end to access other features._
    
## 3. Manage Condition(s)
This feature helps the user to
+ Log symptoms (this enables the user to systematically record symptoms and identify the key triggers).
+ View recommended diet.
+ View recommended daily activities and lifestyle.
  
To use this feature,
1. Go to the home screen.

## 5. Contact a Doctor/Caregiver
This feature helps the user to
+ Glance through a list of doctors and caregivers with their address and contact.
+ Add doctors and caregivers to account.
+ Send health data on the platform directly to the doctor/caregiver.

To access this feature, 
+ Tap on **Contact Doctor**.
+ Select from the list to view doctor/caregiver's details.
+ Tap **Add Professional**.

## 6. Purchase Medication
This feature helps the user to 
+ Order medication from accredited online pharmacy shops with valid doctor's prescription note.
+ Track medication shipment.
+ Check user reviews on pharmacy shops.

 To access this feature, 
+ Tap **Pharmacy Shop**.
+ Tap **Order**.
+ Upload a valid doctor's prescription note containing health insurance details in the next pop-up prompt.
+ Service will verify the note and present a list of pharmacy shops for the user to select from.
  
  _In case insurance details are missing on the note, service will prompt the user to purchase the medication directly via PayPal or Visa._

## 9. Frequently Asked Questions(FAQs)
+ **Can I use the platform to maintain healthy living even when I don't have any outstanding health condition?** Yes. Tap **Only Explore** during the account set up and follow the prompt.
+ **Does anyone else aside from my doctors/ caregivers have access to my health data?** No. Not even the Welth company has access to your personal health data.
+ **Can I cancel a wrong medication order?** Yes. Go to **Pharmacy Shop** > **Cancel Order**.
+ **Can I return an order?** Yes. Go to **Pharmacy Shop** >  **Return Order**.

+ _Alternatively, You can **cancel** or **return** order by simply opening the order **confirmation e-mail**, then tap on either **Cancel Order** or  **Return Order**._
