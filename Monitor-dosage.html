How to Monitor Dose on Welth

Summary

Learn how to record and monitor daily medication intake on Welth.

Audience

Patients, General Users

View Medications

This feature enables the user to:

  • View current medication.
  • Set up medication reminders with timely notifications. For example: If a user is prescribed paracetamol 2×3 times daily (at 9:00, 13:00, and 17:00), Welth will send alerts 10 minutes before each scheduled dose.
  • Mark each dose and monitor consistency.
